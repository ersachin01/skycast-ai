# 🌦️ SkyCast AI — AI Powered Weather Dashboard

SkyCast AI is a modern weather dashboard built using **React + Tailwind CSS + OpenWeatherMap API**.
It provides real-time weather information, intelligent weather insights, air quality monitoring, hourly charts, and a beautiful responsive UI.

---

## ✨ Features

### 🌍 Real-Time Weather

* Current temperature
* Feels like temperature
* Humidity
* Wind speed
* Pressure
* Visibility

### 📅 Forecasts

* 7-Day weather forecast
* Hourly temperature chart
* Sunrise & sunset timing

### 🧠 AI Weather Insights

Smart contextual alerts like:

* Carry umbrella today ☔
* High UV detected ☀️
* Heat warning 🔥
* High humidity alert 💧
* Outdoor activity suggestions 🌤️

### 🌫️ Air Quality Monitoring

* AQI status
* Pollution level indicators

### 🎨 Modern UI/UX

* Glassmorphism design
* Fully responsive layout
* Dark / Light mode
* Smooth animations
* Clean dashboard experience

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/skycast-ai.git
```

### 2️⃣ Navigate to Project

```bash
cd skycast-ai
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Create `.env` File

Create a `.env` file in the root directory:

```env
VITE_WEATHER_API=your_api_key_here
```

Get your free API key from:
[https://openweathermap.org/api](https://openweathermap.org/api)

### 5️⃣ Start Development Server

```bash
npm run dev
```

---

## 🧪 Build for Production

```bash
npm run build
```

## ☁️ Deployment

This project is deployed using **Vercel**.

### Deploy Steps

1. Push project to GitHub
2. Import repository in Vercel
3. Add Environment Variable:

```env
VITE_WEATHER_API=your_api_key
```

4. Deploy 🚀
